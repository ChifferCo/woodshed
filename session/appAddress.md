- The person is not on this machine: a `localhost` or `127.0.0.1` address means nothing to them, and a tunnel (ngrok, cloudflared) is not how they reach the app. This session's app is theirs at {{APP_URL}}, which the console forwards to `127.0.0.1:<frontendPort>` here, from the project file's `app` section; the console's **Open app** button opens it. When you start a server for them to see, run it on that port and give them that address, never a `localhost` one.
  - The server must answer requests for that host name and build its links from that address: allow the host where the dev server checks it (Vite's `server.allowedHosts`, webpack's `allowedHosts`), and set its base URL where it has one (Hugo: `hugo server --bind 127.0.0.1 --port <frontendPort> --baseURL {{APP_URL}} --appendPort=false`).
