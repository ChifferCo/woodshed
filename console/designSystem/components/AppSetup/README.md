# Set up app

Use the existing `dialog.confirm`, `field-label`, `field`, `sub`, `form-error` and `dialog-actions` styles.
The Save in select defaults to This Woodshed; Repository is an explicit alternative. Explain scope, committing and
repository precedence before the action. The action requests discovery and start/stop verification from the agent.
An error stays in the dialog. Cancel and Escape close it without sending a request.
