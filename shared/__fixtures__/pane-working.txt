  What the review changed

  plan-critic returned 5 blocking + 7 advisory. All folded in. The three that genuinely changed the design:

  Scanning the whole screen would have been a self-inflicted bug. Claude's own output persists on screen and can contain the markers verbatim —
  the critic found esc to rewind sitting in a live pane, and the session implementing this will have esc to interrupt in its own diff. It would
  have read "working" permanently. Now anchored to the footer segment after the last ─── rule.

  session_activity is the wrong clock — 224s stale on a session redrawing every frame, while window_activity was current to the second. It broke
  both the cache and the sort key. Caught by measuring; AC8 was the only criterion that would have found it, and it's manual.

  Folding status into usageLine's level would have put a ⚠ on every session — level is truthy-tested to prepend a warning triangle, and the
  class-removal list is hardcoded so classes would accumulate every poll. Now a separate field.
